## 建议的阅读顺序

1. `README.md` → 建立全局印象（三条链路 + 已验收结论）
2. `docs/adr.md` → 看"每个决策放弃了什么"，这是项目最核心的部分
3. `src/main/java/.../link/service/` → 创建链路 `LinkCreateService`、跳转链路 `LinkQueryService`
4. `src/main/java/.../idgen/`、`shortcode/` → 发号器与短码生成两个深挖点
5. `src/main/resources/sharding.yaml` + `sql/sharding_*.sql` → 分库分表落地
6. `benchmark/README.md` + `benchmark/results/baseline.md` → 数据与归因
