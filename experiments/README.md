# 历史实验

本目录保存分库分表、双缓冲号段和数值短码编码的历史实验，便于比较设计取舍。它们不参与 Maven 的编译、测试、打包或 Spring 组件扫描，不能通过打开一个配置开关恢复到主版本。

- `idgen/`：号段预加载、动态步长、数据库 CAS 及对应测试快照。
- `shortcode/`：数值 Base62、Feistel 备选方案及对应测试快照。自定义 Feistel 仅作实验，不应当作生产加密组件使用。
- `sharding/`：两库八表规则、建表和迁移脚本快照。SQL 可能包含覆盖、清理及函数操作，不要直接对现有数据库执行。

主版本采用单库、MyBatis-Plus 内置主键、随机短码与唯一索引。旧实验依赖、实体和接口已从主版本移除，因此这些文件仅供阅读，历史测试结果不算当前主版本的验证结果。

恢复实验时应在独立分支和独立数据库补齐依赖、组件及验收测试，而不是混入默认启动流程。当前架构与升级边界见 [精简说明](../docs/simplification.md)。
